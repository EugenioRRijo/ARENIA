# Plan de implementación — F.1 adelantada: API, simulador, UI multipágina y gestión 3D (I3.1)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Exponer el núcleo por HTTP (FastAPI + OpenAPI), ejercitar el ciclo de precios con un simulador determinista, extender la UI a multipágina y cruzar la compuerta G1 con el adaptador civil IFC y un visor 3D.

**Architecture:** `api/` y `ui/` son capas de composición: llaman a `core` (y a `adapters/` para cómputos) y no contienen lógica de negocio. `Decimal` viaja como **texto** en el JSON. El modelo 3D de muestra se genera programáticamente con ifcopenshell; el adaptador IFC devuelve `ItemComputo` con `origen_id` = GlobalId y la aceptación de G1 compara contra el cálculo manual (0,224 m3).

**Tech Stack:** FastAPI + uvicorn (extra `api`), Streamlit (extra `ui`), ifcopenshell 0.8 (extra `civil`), SQLAlchemy/SQLite, pandas/openpyxl, pytest + httpx TestClient. Todo ya declarado en `pyproject.toml`/`uv.lock` — **no se añaden dependencias**.

**Spec:** `docs/superpowers/specs/2026-08-31-f1-api-simulador-design.md` (leerla entera antes de cualquier tarea; este plan argumenta desde ella).

- `core/contracts/` congelado; no se modifica ninguna prueba existente para ponerla en verde.
